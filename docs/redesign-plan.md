# Active Recall Coach redesign plan

## Product direction
- Replace the old demo-like experience with a calm, professional four-step workflow: upload, generate session, recall, review report.
- Prioritize retrieval practice and feedback quality over visual decoration.
- Make the UI feel academically credible and reliable, rather than playful or novelty-driven.

## What changed
- Added a stepper-based study flow with clearer progression.
- Reworked the source upload screen to feel like a serious study workspace.
- Introduced a distraction-free recall screen with typed and voice modes.
- Replaced the previous keyword-only output with a more structured learning report.
- Added a simple progress dashboard for trend tracking.

## Next priorities
1. Replace the heuristic engine with a richer semantic comparison model.
2. Add structured prompting for better explanation quality and misconception detection.
3. Introduce spaced repetition scheduling and review reminders.
4. Improve accessibility and add a true mobile-optimized recall experience.
